# 🎬 장면 생성기 · 미니맵 HUD (Scene Studio)

### 방법 1. SillyTavern 안에서 설치 (권장)
1. 상단의 **확장 프로그램(🧩)** 아이콘 → **Install extension**
2. 이 저장소의 GitHub 주소를 붙여 넣고 설치
3. 페이지를 새로고침해요 (**Ctrl+F5** 권장)
설치되면 확장 프로그램 설정에 **🎬 장면 생성기 · 미니맵 HUD** 항목이 생겨요.

---

## 처음 세팅하기

### 1) API 키와 이미지 모델
확장 설정의 **장면 이미지 생성** 섹션에서:
1. **생성 방식**을 골라요.
   - *Agent Platform API*: 프로젝트 ID는 비워도 이미지 생성은 돼요(키만 쓰는 express 모드).
   - *Gemini Developer API*: AI Studio 키를 넣어요.
2. **API 키**를 넣어요.
3. **모델**은 기본값(`gemini-3.1-flash-image`)을 쓰거나 직접 입력해요. 모델 이름은 Google이 바꿀 수 있으니 [공식 문서](https://ai.google.dev/gemini-api/docs)를 확인해 주세요.
4. **연결 테스트**를 눌러 확인해요. (이미지를 만들지 않아서 요금이 들지 않아요)

### 2) 장소 분석
1. 채팅을 열고 **장면 창 → 장소·지도 탭**으로 가요.
2. **장소·마커 자동 분석**을 눌러요. (모델 호출 1회)
3. 위치가 어색하면 지도에서 핀을 드래그해서 옮기고, 이름·별칭·묘사는 목록에서 고쳐요.

### 3) 이미지 만들기
- 장소가 감지되면 장면 창의 **장면 이미지 생성** 버튼을 눌러요.
- 장소가 바뀔 때 자동으로 만들고 싶다면 **옵션 탭 → 장소가 바뀔 때만 장면 자동 생성**을 켜요. (요금이 자동으로 나가니 주의)
- **화풍 프롬프트**는 직접 입력해서 이름을 붙여 저장 아이콘(💾)으로 여러 개 저장할 수 있어요. 

### 4) 영상(선택)
**움직이는 장면 (Veo 영상)** 섹션에서 설정해요.
- **Agent Platform**: *프로젝트 ID*와 *리전*(`us-central1` 권장)이 **꼭 필요**해요. 키만으로는 `400 Invalid resource field value` 오류가 나요.
- **Gemini Developer API**: AI Studio 키로 바로 쓸 수 있어요.
- API 키가 영상 요청을 거부하면 영상 전용 키나 액세스 토큰을 따로 넣을 수 있어요.

### 5) (선택) 텍스트 분석 모델 따로 쓰기
설정 맨 위 **텍스트 분석용 연결 프로필**에서 Connection Manager 프로필(예: Flash 계열)을 고르면, 채팅 내용을 보내지 않고 필요한 정보만 보내서 훨씬 저렴해요. 비워 두면 채팅에 연결된 모델을 써요.

## 사용법

### 미니맵
| 조작 | 동작 |
|---|---|
| 마우스 휠 / 두 손가락 | 확대·축소 |
| 드래그 | 지도 이동 |
| 더블클릭 | 전체 보기 |
| 빨간 내 위치 아이콘 더블클릭 | 지금 내가 있는 지도로 복귀 |
| 헤더 ▾ 버튼 (미니맵만 쓸 때) | 지도 목록, 내 위치로 돌아가기, 접기/펴기 |
| Shift+드래그 / 테두리 드래그 | HUD 위치 이동 (장면 위에 얹었을 때) |
| 모서리 손잡이 | 크기 조절 |

### 장면 창
- 제목줄: `<` `>` 이전/다음 이미지·영상, 핀(기준 이미지 고정), ↻ 다시 만들기, 필름(영상), 휴지통(삭제)
- 장면 위 드래그로 둘러보기, 휠로 확대, 더블클릭으로 원위치, 영상은 클릭으로 재생/정지
- **기준 이미지**: 고정해 두면 이후 이미지를 만들 때 캐릭터·화풍 참조로 같이 보내요 (옵션에서 자동 고정 여부 선택)

### 영상 취소
영상을 만드는 동안 장면 오른쪽 아래에 **취소** 버튼이 떠요. 이미 Google에 요청이 들어갔다면 서버에서는 계속 진행돼 **요금이 나올 수 있어요**. 이 확장은 결과를 받지 않고 기다리기만 멈춰요.

### 이미지 관리
이미지 탭에서 썸네일을 보고 선택해 삭제할 수 있어요(서버 파일도 함께 삭제). 더블클릭하면 원본 크기로 크게 볼 수 있고, **최대 보관 장수**를 정해 오래된 것을 자동 정리할 수도 있어요.

## 요금 안내

- 이미지·지도·영상은 **내 Google API 키로 요금이 발생**해요. 단가는 Google 가격표를 확인해 주세요.
- 영상은 초 단위로 과금되고, 확장이 보여주는 예상 요금은 참고용이에요.
- 텍스트 분석(장소 분석, 마커 추적, 외형 추출, 장면 연출)은 연결된 모델의 요금이 들어요. 연결 프로필로 저렴한 모델을 쓰면 줄일 수 있어요.
- **기록 탭**에서 호출별 토큰을 확인할 수 있어요. 모델 호출 수치는 이 확장이 추가한 지시문과 응답만 센 **추정치(~)**예요.

## 개인정보와 데이터

**이 확장은 제작자에게 아무 데이터도 보내지 않아요.** 통계 수집이나 외부 스크립트가 없고, 요청은 아래 두 곳으로만 가요.
1. 내 SillyTavern 서버 (`/api/...`)
2. 내가 넣은 키로 호출하는 Google 서버 (`generativelanguage.googleapis.com`, `aiplatform.googleapis.com`)

### Google로 전송되는 것
- **이미지 생성**: 화풍·장소 묘사, 최근 대화에서 요약한 "지금 장면" 한 문장, 인물 외형 태그, 참조 이미지(기준 이미지, 건물 이미지, 페르소나 아바타, 캐릭터 카드 이미지)
- **지도 생성**: 장소 이름·종류·좌표가 그려진 스케치 이미지
- **영상**: 장면 이미지 한 장과 움직임 지시문
- **텍스트 분석**: 캐릭터·페르소나 설명, 로어북 일부, 최근 대화 일부 → *채팅 모델 또는 고른 연결 프로필*로 전송 

### 내 컴퓨터(서버)에 저장되는 것
- 만든 이미지·영상: `user/images/minimap/` (또는 `user/files/`)
- 채팅 파일: 장소, 마커, 이미지 목록, 장면 요약 문장
- 확장 설정(`settings.json`): **API 키가 평문으로 저장돼요.** 이 파일을 공유하거나 저장소에 올리지 마세요.
- 사용 기록: 종류·장소·토큰 수·영상 초/예상 요금 (프롬프트 전문은 저장하지 않아요)

### 안전 필터
이미지·영상이 안전 필터에 걸리면 오류 메시지만 보여주고 **자동으로 다시 시도하지 않아요.** 반복해서 정책 위반으로 확정되면 Google이 API 접근을 제한할 수 있으니, 필터를 우회하려는 재시도는 피하세요. API 전용 Google Cloud 프로젝트를 따로 쓰는 것을 권해요.

## 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| 버튼이 세로로 늘어나고 스타일이 깨짐 | 브라우저 캐시예요. **Ctrl+F5**로 새로고침해 주세요. |
| `403 … Generative Language API has not been used` | 키가 Agent Platform용이에요. 생성 방식을 *Agent Platform*으로 바꿔 보세요. |
| 영상 `400 Invalid resource field value` | Agent Platform 영상은 **프로젝트 ID와 리전**이 필요해요. |
| 영상 `401/403` | 영상 전용 API 키나 액세스 토큰을 넣거나 Gemini Developer API 방식을 써 보세요. |
| `404` / 모델을 찾을 수 없음 | 모델 이름이 바뀌었거나 그 리전에서 열려 있지 않아요. 모델 칸에 직접 입력해 보세요. |
| `Failed to fetch` / CORS | 브라우저에서 Google을 직접 호출하는 방식이라 환경에 따라 막힐 수 있어요. |
| `429` | 호출 한도 초과예요. 잠시 후 다시 시도해 주세요. (토큰은 쓰이지 않아요) |
| "이미지가 생성되지 않았어요 (SAFETY 등)" | 안전 필터예요. 묘사를 바꾸거나, 아바타 참조 이미지가 원인일 수 있어 *아바타 참조*를 꺼 보세요. |
| 연결 프로필 목록이 비어 있음 | Connection Manager 확장을 켜고 프로필을 만들어 주세요. |
| 페르소나 사진이 외형 탭에 안 보임 | SillyTavern 화면 구조에 따라 못 찾을 수 있어요. 이슈로 알려 주세요. |
| 방마다 내부 지도가 따로 생김 | 장소·지도 탭의 **내부 지도 정리** 버튼을 눌러 건물 하나로 합쳐요. |

## 알려진 한계

- 이미지 모델 특성상 **같은 인물이 항상 똑같이 나오는 것은 보장되지 않아요.** 기준 이미지 고정과 참조 이미지로 줄일 수 있어요.
- 영상은 짧은 클립이에요. 인물이 길게 움직이는 장면에는 맞지 않아요.
- 모델 이름과 가격은 Google이 바꿀 수 있어요. 최신 정보는 Google 문서를 확인해 주세요.

## 제거 방법
확장 프로그램 목록에서 삭제하거나 설치한 폴더를 지워요. 만든 이미지가 필요 없다면 `user/images/minimap/` 폴더도 지우세요. 채팅 파일에 저장된 장소·이미지 목록은 해당 채팅에만 남아요.
